WHAT SYNIX MANAGES

Server setup, monitoring, maintenance, and recovery.

Synix brings the jobs required to run a personal dedicated server into one Windows application while keeping files, commands, checks, and results visible.

Setup and configuration

Go from a game name to a manageable server.

Choose a built-in definition and Synix adapts the setup window to the game instead of asking every user to learn every command-line switch.

01

Template-aware server setup

Supported controls unlock automatically for each game: identity, world, map, player limit, ports, RCON, credentials, automation, frameworks, and launch options.

  • Validated paths and port-conflict checks
  • Config templates for games that require them
  • Steam account login only when installation requires it
02

SteamCMD ready

Synix checks and prepares SteamCMD, then installs, updates, repairs, and validates server files with visible progress.

03

Format-aware config editor

Edit supported INI, XML, JSON, and space-delimited files without rewriting their comments, layout, or key order.

04

Safe extra arguments

Synix keeps game arguments flexible while blocking Windows command-injection operators and hiding secrets from logs.

05

Server frameworks

Install supported runtimes such as Fabric, Forge, and Oxide while leaving third-party plugins under the user’s control.

Daily management

Everything important stays close.

Start, restart, and verified stop

Pre-flight checks, clean shutdown workflows, process tracking, and startup probes reduce duplicate processes and unclear states.

◎

Dashboard and live monitoring

See state, uptime, players, CPU, RAM, ports, activity, diagnostics, and per-server process details.

⟳

Backups and restore

Create retained archives, restore a chosen backup safely, and transfer all Synix data to another computer.

⚙

Automation

Update or back up before launch, schedule restarts, limit SteamCMD speed, and queue game-file verification.

✉

Discord routing

Use one master webhook or route status, backup, update, maintenance, and failure events to different channels.

✓

System troubleshooter

Check runtimes, missing files, config health, ports, firewall rules, disk space, leftover processes, logs, and update health.
