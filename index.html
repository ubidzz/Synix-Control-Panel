SYNIX v1.0.22 · WINDOWS 10 & 11

Run dedicated game servers from one Windows app.

Choose a game and the settings you want. Synix handles installation, startup, monitoring, backups, updates, and common maintenance without making you build command files by hand.

SERVER SETUP

Pick the game. Enter the settings. Save the server.

Synix reads its built-in game definition and displays the options that apply to that server. Ports, players, worlds, passwords, RCON, automation, and launch settings stay in normal form controls.

  • SteamCMD installation and repair
  • Template-aware configuration fields
  • Port-conflict and argument checks
  • Steam account sign-in when a title requires it
See all setup and configuration features →

RUN & MONITOR

See what every managed server is doing.

The dashboard shows server state, uptime, players, CPU, RAM, and current activity. The Resource Monitor identifies the exact server process behind the totals.

  • Verified start, stop, and monitoring results
  • Live process CPU and memory use
  • Activity and diagnostic messages
  • Per-server Discord event routing
Open the full screenshot gallery →

MAINTAIN & RECOVER

Back up servers and move Synix without rebuilding everything.

Create server backups, restore a selected backup, set retention limits, or package the entire C:\Synix folder for another PC. Transfer packages can be encrypted and verified before import.

  • Server backup and staged restore
  • Encrypted or normal whole-app transfer
  • Transfer size, free-space, and time estimates
  • Update, repair, and verification queue
See backup and maintenance tools →

LOCAL-FIRST BY DESIGN

Synix manages your servers on your PC.

There is no Synix cloud account or public web panel to expose. Routine use does not require permanent administrator access, and the source is available to inspect on GitHub.

Protected valuesSaved passwords and webhooks are protected for the current Windows user.
Privacy modeHide IP addresses and sensitive details during screen sharing.
Visible commandsReview default arguments, extra arguments, activity, and verification results.
No plugin loadingGame definitions are built into the application instead of loading executable plugins.
