First launch

What to expect.

Download from the official release

Use this website, WinGet, or the Synix GitHub repository. Avoid unofficial mirrors.

Review the Windows warning

Synix is independently developed and does not have a paid code-signing certificate. SmartScreen may show a reputation warning for a new release.

Open Synix

SteamCMD is checked automatically. When the footer reports it is ready, choose Add Server.

Keep your data

Updating the application does not remove the servers, worlds, backups, or settings stored under C:\Synix.

Installer change

If you installed Synix v1.0.20 or earlier with the old SynixSetup.exe installer, uninstall that application entry first, then install the current SynixSetup.msi. The server data under C:\Synix is not removed by that uninstall.
